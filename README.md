# Transcoder

A modern, privacy-focused text and data conversion toolkit that runs entirely in your browser.

**🌐 Live Demo:** https://graph90.github.io/pages/transcoder.html

**📦 Repository:** https://github.com/graph90/transcoder

---

## Features

* 🔄 Base64 Encode & Decode
* 🔢 Binary ↔ Text
* 🧮 Hex ↔ Text
* 🔠 ASCII ↔ Text
* 🌍 Unicode Escape ↔ Text
* 🔗 URL Encode & Decode
* 📝 HTML Entity Encode & Decode
* 📄 JSON Format, Minify & Validate
* 🔐 SHA-1, SHA-256, SHA-384 & SHA-512 Hashing
* 🔁 ROT13
* 📡 Morse Code
* 🔢 Number Base Converter
* 🤖 Automatic Format Detection
* 📋 One-click Copy & Paste
* 💾 Download Results
* 🕘 Conversion History
* 🌙 Modern Responsive Interface

---

## Why Transcoder?

Unlike many online converters, **Transcoder performs every conversion locally in your browser.**

* ✅ No uploads
* ✅ No tracking
* ✅ No server processing
* ✅ No external dependencies
* ✅ Works completely offline

Your data never leaves your computer.

---

## Offline Usage

Download or clone this repository:

```bash
git clone https://github.com/graph90/transcoder.git
```

Then simply open **index.html** in any modern web browser.

No installation.
No build tools.
No web server.
No internet connection required.
